Conseils de sécurité

Questions fréquentes

Pour créer un compte, rendez-vous sur la page d’inscription et renseignez votre nom, prénom, adresse e-mail et mot de passe.

  • Votre adresse e-mail doit être valide.
  • Le mot de passe doit contenir au moins 6 caractères.
  • Après inscription, vous pouvez accéder à votre espace client.

Vérifiez d’abord votre adresse e-mail et votre mot de passe. Si vous avez oublié votre mot de passe, utilisez la fonction « Mot de passe oublié ».

  • Vérifiez qu’il n’y a pas d’espace avant ou après votre e-mail.
  • Vérifiez que votre mot de passe ne contient pas d’erreur de saisie.
  • Essayez de vous connecter depuis un autre navigateur.
  • Si le problème persiste, contactez l’agence.

Rendez-vous dans la rubrique Mon compte. Vous pouvez y consulter et modifier vos informations personnelles.

  • Nom et prénom
  • Adresse e-mail
  • Numéro de téléphone
  • Adresse postale
  • Préférences de contact

Le coffre électronique protège l’accès à vos documents personnels grâce à un code à 4 chiffres.

  • Lors de la première utilisation, créez votre code.
  • Confirmez ensuite votre code pour éviter toute erreur.
  • À chaque connexion, saisissez ce code pour déverrouiller le coffre.
  • Ne communiquez jamais ce code à une autre personne.

Pour des raisons de sécurité, l’agence ne peut pas connaître votre code personnel.

Contactez l’agence depuis la messagerie ou par e-mail. Après vérification de votre identité, un nouveau code pourra être configuré.

Dans la rubrique Mes documents, utilisez la zone « Transférer un document à l’agence ».

  • Cliquez sur la zone de dépôt ou glissez votre fichier.
  • Vérifiez le nom et la taille du document sélectionné.
  • Cliquez sur « Transférer à l’agence ».
  • Le document est enregistré et l’agence est notifiée.

Les formats suivants sont généralement acceptés :

  • PDF
  • JPG
  • JPEG
  • PNG
  • WEBP
  • DOC
  • DOCX

La taille maximale recommandée est de 10 Mo par fichier.

Dans la rubrique Messagerie, cliquez sur « Nouveau message ».

  • Renseignez l’objet de votre message.
  • Écrivez votre message dans la zone prévue.
  • Ajoutez éventuellement une pièce jointe.
  • Cliquez sur « Envoyer ».

Un accusé de réception est envoyé à votre adresse e-mail.

Dans la messagerie, ouvrez le dossier Messages envoyés.

Vous y retrouverez les messages que vous avez envoyés à l’agence, ainsi que les brouillons enregistrés.

Ouvrez le message concerné, puis cliquez sur « Mettre à la corbeille ».

Le message sera déplacé dans la corbeille. Depuis la corbeille, vous pouvez le restaurer ou le supprimer définitivement.

Dans la messagerie, cliquez sur l’icône de cloche, puis sur « Activer les alertes ».

Votre navigateur peut vous demander l’autorisation d’afficher des notifications. Acceptez-la pour recevoir une alerte lorsqu’un nouveau message arrive.

Dans la rubrique Mes documents, descendez jusqu’à la section « Documents officiels de l’agence ».

  • Conditions générales
  • Politique de confidentialité
  • Mentions légales
  • Charte client

Cliquez sur un document pour l’ouvrir au format PDF.

Pour protéger votre compte :

  • Utilisez un mot de passe unique et difficile à deviner.
  • Ne partagez jamais votre mot de passe ou votre code de coffre.
  • Déconnectez-vous après utilisation, surtout sur un appareil partagé.
  • Ne cliquez pas sur des liens suspects reçus par e-mail.
  • Contactez l’agence si vous suspectez une utilisation frauduleuse.

Si une page ne s’affiche pas correctement :

  • Rechargez la page avec Ctrl + F5.
  • Videz le cache du navigateur.
  • Désactivez temporairement les extensions de blocage.
  • Essayez un autre navigateur.
  • Vérifiez votre connexion Internet.
